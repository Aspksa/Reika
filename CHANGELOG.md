# История Reika

## 0.15.0

- **Исправить ответы Cloud.ru и добавить историю анализов** — Результат анализа отображается для большего числа форматов ответов; историю можно открыть после перезагрузки и отметить исправленной. Уведомления появляются при новых событиях на странице проекта.

Полное описание: [releases/0.15.0.md](releases/0.15.0.md).

## 0.14.0

- **Анализ проекта через Cloud.ru и версии разделов** — Можно запустить обзор проекта моделью Cloud.ru после сохранения ключа на Windows и получить рекомендации на странице проекта. Запрос может тарифицироваться Cloud.ru.

Полное описание: [releases/0.14.0.md](releases/0.14.0.md).

## 0.13.0

- **Настройки внешнего вида и подробный каталог моделей** — Можно настроить внешний вид Reika под себя и сравнить назначение семи моделей перед выбором. Сохранение API-ключа на Windows по-прежнему защищено DPAPI.

Полное описание: [releases/0.13.0.md](releases/0.13.0.md).

## 0.12.0

- **Новый дизайн каталога модулей Reika** — Пользователь видит компактную сводку проекта и читабельный каталог; подробности, поиск, список, карта связей и история остаются доступны.

Полное описание: [releases/0.12.0.md](releases/0.12.0.md).

## 0.11.0

- **Настройки проекта: Cloud.ru, безопасное сохранение ключа и выбор модели** — Появилась страница Cloud.ru с полем ключа, выбором модели, каталогом описаний и ценами. Выбор модели и сохранение настроек сами по себе не отправляют платных запросов к Cloud.ru.

Полное описание: [releases/0.11.0.md](releases/0.11.0.md).

## 0.10.0

- **Автоматическая локальная диагностика проекта и мониторинг архитектуры** — На странице видны реальное время последней проверки, число файлов и найденные проблемы. Новые каталоги предлагаются к регистрации, но код и конфигурация не изменяются автоматически. Проверка запускается раз в 30 секунд, раз в пять или тридцать минут либо вручную.

Полное описание: [releases/0.10.0.md](releases/0.10.0.md).

## 0.9.0

- **Современный центр архитектуры, граф связей и панель модулей** — Выбор модуля открывает его подробности; карта показывает направление и тип связей; фильтры компактнее, визуальные состояния понятнее, есть подсветка и адаптация для мобильных экранов.

Полное описание: [releases/0.9.0.md](releases/0.9.0.md).

## 0.8.0

- **Вкладки проекта, режимы просмотра и сравнение версий** — Можно отдельно просматривать модули, зависимости и историю, выбирать плотность карточек, скрывать технические детали и сравнивать две версии рядом.

Полное описание: [releases/0.8.0.md](releases/0.8.0.md).

## 0.7.0

- **Удобная навигация и современное оформление страницы Проект** — Теперь можно быстрее переходить к интересующему разделу, одним нажатием сбрасывать фильтры и читать историю и сведения о модулях без лишней визуальной нагрузки.

Полное описание: [releases/0.7.0.md](releases/0.7.0.md).

## 0.6.0

- **Поиск, показатели, категории и история раздела Проект** — На странице «Проект» доступны быстрый поиск, четыре показателя, фильтрация по категориям и статусам, раскрываемые списки файлов и связей, поиск выпусков и выбор вида обновления.

Полное описание: [releases/0.6.0.md](releases/0.6.0.md).

## 0.5.0

- **Журнал проблем, действий ИИ-агентов и точных связей коммитов** — Можно фиксировать ошибки и действия агентов через консольные команды, просматривать подтверждённые по сообщениям коммитов связи и находить коммиты без задачи. Старый порядок нумерации и публикации релизов сохраняется.

Полное описание: [releases/0.5.0.md](releases/0.5.0.md).

## 0.4.0

- **Автоматические выпуски и понятная карта модулей** — Появился раздел «Проект», где можно выбрать модуль и увидеть связанные части. Версии готовятся автоматически после слияния описанных изменений. Готовый выпуск публикуется только после проверок Windows, Linux, Node.js и браузера.
- **Согласованное получение файлов запуска из Git** — Файлы запуска сохраняют одинаковые байты в архиве и Git checkout, а диагностика подготовки выпуска стала понятнее.

Полное описание: [releases/0.4.0.md](releases/0.4.0.md).

## 0.3.0 — 25 октября 2026

- Введён единый реестр версий проекта и девяти компонентов.
- Добавлен каталог файлов с версиями компонентов и контрольными суммами.
- Версии компонентов отображаются в разделе «Система».
- Добавлены команды согласования и повышения версий, проверка в GitHub Actions.

Версии компонентов впервые поставлены на учёт в этой версии. Базовая отметка для всех — 0.3.0; дальше номера компонентов можно изменять отдельно.

## 0.2.0 — 25 октября 2026

- Добавлены Node.js, Vite, сборка интерфейса и режим разработки.
- CSS разделён на шесть модулей; добавлены обновления CSS без перезагрузки в режиме разработки.
- Готовая сборка включена в репозиторий; Python проверяет её SHA-256.
- Исправлено изменение байтов ресурсов при получении репозитория на Windows.

## 0.1.0 — 25 октября 2026

- Создана основа Reika: BAT, проверка Python, свободный порт, трей и браузер.
- Добавлены русский интерфейс, темы, состояние системы и журналы.
- Добавлены локальные ограничения доступа и проверки Windows, Linux и браузера.
