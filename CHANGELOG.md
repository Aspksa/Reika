# История Reika

## 0.24.0

- **Clarity II: короткие рабочие экраны, прямые ссылки и компактная навигация** — Быстрее доступ к модулям и настройкам: список короче, на каждой рабочей странице сразу видны нужные инструменты, мобильные вкладки занимают одну строку, а URL можно сохранить.

Полное описание: [releases/0.24.0.md](releases/0.24.0.md).

## 0.23.0

- **Clarity: спокойная навигация, шесть рабочих зон и адаптивный дизайн Reika** — Вместо длинной перегруженной страницы пользователь сразу видит обзор и переходит к конкретной задаче за одно действие. Упрощены навигация на телефоне, настройки и поиск моделей без удаления существующих функций.

Полное описание: [releases/0.23.0.md](releases/0.23.0.md).

## 0.22.1

- **Автоматическая подготовка Python при запуске Reika без установленного интерпретатора** — После распаковки исходников Reika сможет самостоятельно подготовить Python без администратора. При использовании готового ZIP-выпуска с Python дополнительная загрузка не требуется. При отсутствии интернета показана понятная причина и способ автономного запуска.

Полное описание: [releases/0.22.1.md](releases/0.22.1.md).

## 0.22.0

- **История локальной диагностики проекта** — В разделе «Проект» видно, какая проблема появилась впервые, какая остаётся и какая исчезла. Ручная проверка сразу обновляет результат; история доступна после перезапуска Reika.
- **Проверять переход к актуальной истории модуля** — Автоматический выпуск не останавливается из-за устаревшего ожидания в браузерном тесте; переход к действительной истории модуля продолжает проверяться.

Полное описание: [releases/0.22.0.md](releases/0.22.0.md).

## 0.21.0

- **Добавить Python в готовый архив Windows** — Начиная со следующего выпуска готовый архив Windows x64 запускается без отдельной установки Python. Запуск из исходников остаётся доступен с установленным Python.

Полное описание: [releases/0.21.0.md](releases/0.21.0.md).

## 0.20.0

- **Настройки рабочего пространства проекта** — Пользователь один раз задаёт удобный вид проекта и частоту проверки. Проект открывается на выбранной вкладке, карточки и мониторинг сохраняют выбранные параметры после перезапуска браузера.

Полное описание: [releases/0.20.0.md](releases/0.20.0.md).

## 0.19.0

Полное описание: [releases/0.19.0.md](releases/0.19.0.md).

## 0.4.0

- **Автоматические выпуски и понятная карта модулей** — Появился раздел «Проект», где можно выбрать модуль и увидеть связанные части. Версии готовятся автоматически после слияния описанных изменений. Готовый выпуск публикуется только после проверок Windows, Linux, Node.js и браузера.
- **Согласованное получение файлов запуска из Git** — Файлы запуска сохраняют одинаковые байты в архиве и Git checkout, а диагностика подготовки выпуска стала понятнее.

## 0.3.0 — 25 октября 2026

- Введён единый реестр версий проекта и девяти компонентов.
- Добавлен каталог файлов с версиями компонентов и контрольными суммами.
- Версии компонентов отображаются в разделе «Система».
- Добавлены команды согласования и повышения версий, проверка в GitHub Actions.

Версии компонентов впервые поставлены на учёт в этой версии. Базовая отметка для всех — 0.3.0; дальше номера компонентов можно изменять отдельно.

## 0.2.0 — 25 октября 2026

- Добавлены Node.js, Vite, сборка интерфейса и режим разработки.
- CSS разделён на шесть модулей; добавлены обновления CSS без перезагрузки в режиме разработки.
- Готовая сборка включена в репозиторий; Python проверяет её SHA-256.
- Исправлено изменение байтов ресурсов при получении репозитория на Windows.

## 0.1.0 — 25 октября 2026

- Создана основа Reika: BAT, проверка Python, свободный порт, трей и браузер.
- Добавлены русский интерфейс, темы, состояние системы и журналы.
- Добавлены локальные ограничения доступа и проверки Windows, Linux и браузера.
