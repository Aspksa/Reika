## Новая возможность: Настройки проекта: Cloud.ru, безопасное сохранение ключа и выбор модели

В боковое меню добавлен раздел «Настройки проекта». В нём можно выбрать модель Evolution Foundation Models, увидеть назначение каждой модели и ориентировочную стоимость одного миллиона входных и выходных токенов в рублях. API-ключ сохраняется локально для текущего пользователя Windows с помощью DPAPI, в API обратно не выдаётся. Сохранённый ключ можно удалить. На других ОС запись ключа отключена до появления поддерживаемого защищённого хранилища.

**Зачем:** Для дальнейших функций анализа проекта нужна явная настройка облачной модели, без помещения ключа в исходники, браузерное хранилище, Git или журнал.

**Что изменится для пользователя:** Появилась страница Cloud.ru с полем ключа, выбором модели, каталогом описаний и ценами. Выбор модели и сохранение настроек сами по себе не отправляют платных запросов к Cloud.ru.

**Проверки, описанные автором:**
- Браузерные проверки доступности страницы, списка моделей и описаний.
- Серверные проверки закрытости ключа и отклонения запросов с постороннего Origin.
- GitHub Actions запускает полный набор проверок Windows, Linux, Node.js и браузера.

**Ограничения и известные проблемы:**
- Стоимость по опубликованному каталогу Cloud.ru может измениться; реальная тарификация определяется действующим тарифом в личном кабинете.
- Ключ защищён средствами профиля Windows DPAPI. На других операционных системах сохранение ключа отключено.
- Подключение модели для чата и отправка запросов пока не реализованы: это настройки будущего подключения. Проверка доступности модели также пока не выполняется.
- В каталог включены семь проверенных текстовых моделей; прочие услуги Foundation Models будут добавляться отдельным обновлением.

**Переход на новую версию:**
- Откройте «Настройки проекта» в боковом меню Reika.
- Выберите модель и сохраните API-ключ в Windows. Не добавляйте ключ в репозиторий.
- Сведения о тарифах: https://cloud.ru/products/evolution-ai-factory/catalog-foundation-models
