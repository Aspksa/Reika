## Новая возможность: Анализ проекта через Cloud.ru и версии разделов

В разделе «Проект» добавлены переход к настройкам и ручной анализ зарегистрированных файлов кода через выбранную модель Cloud.ru. Анализ показывает возможные ошибки, аномалии и идеи развития. В боковом меню рядом с каждым разделом показана версия его компонента. Для анализа ограничены число и размер файлов; ключ остаётся на сервере, файлы журналов, настроек и сборки исключены.

**Зачем:** Пользователю нужны заметный доступ к настройкам, версии разделов и инструмент поиска проблем проекта.

**Что изменится для пользователя:** Можно запустить обзор проекта моделью Cloud.ru после сохранения ключа на Windows и получить рекомендации на странице проекта. Запрос может тарифицироваться Cloud.ru.

**Проверки, описанные автором:**
- npm run build, npm run check, npm run test:versions, npm run test:release, npm run check:build — успешно.
- Python unittest discover: 33 теста пройдены, 3 Windows-проверки пропущены на Linux.
- Браузерный smoke-тест пройден: навигация, версии, ссылка на настройки и сообщение при отсутствии ключа.
- Тест вызова Cloud.ru выполнен с подменённым транспортом: проверены выбранные файлы, модель и отсутствие ключа в теле запроса.

**Ограничения и известные проблемы:**
- Для реального запроса нужен сохранённый ключ Cloud.ru в Windows и доступ к API; в этой среде запрос к модели не выполнялся.
- Анализ ограничен 80 файлами и 120 КБ; вывод модели требует проверки человеком и не гарантирует обнаружение всех ошибок.
- Запуск анализа может расходовать платные токены Cloud.ru.

**Переход на новую версию:**
- После обновления перезапустите Reika. Для анализа сохраните ключ и выберите модель в настройках проекта.
