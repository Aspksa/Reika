## Новая возможность: Настройки рабочего пространства проекта

В настройках проекта появилась отдельная панель рабочего пространства с начальной вкладкой, видом и плотностью карточек, уровнем подробностей и интервалом локальной автопроверки. Параметры применяются сразу, сохраняются в браузере и синхронизируются с управлением на странице проекта. Уведомления размещены рядом с параметрами проверки. Кнопка возврата восстанавливает исходные значения параметров рабочего пространства, не затрагивая тему, ключ Cloud.ru и выбранные уведомления.

**Зачем:** Вид проекта и интервал проверки приходилось менять непосредственно на странице, а после перезагрузки выбор терялся.

**Что изменится для пользователя:** Пользователь один раз задаёт удобный вид проекта и частоту проверки. Проект открывается на выбранной вкладке, карточки и мониторинг сохраняют выбранные параметры после перезапуска браузера.

**Проверки, описанные автором:**
- npm run build — успешно.
- Браузерный smoke-тест: сохранение параметров после перезагрузки, применение в проекте, сброс и адаптивная вёрстка настроек — успешно.
- npm run test:versions: 3 теста пройдены; npm run test:release: 10 тестов пройдены.
- Python unittest: 40 тестов пройдены, 3 Windows-проверки пропущены на Linux.
- npm run check, npm run check:build, npm run release:check и python scripts/chronicle.py validate — успешно.

**Ограничения и известные проблемы:**
- Настройки действуют только в текущем браузере и не синхронизируются между компьютерами.
- При запрете хранилища браузера выбор сохраняется только до закрытия вкладки.

**Переход на новую версию:**
- Откройте «Настройки проекта» → «Рабочее пространство» и выберите удобные параметры. Исходные значения повторяют прежнее поведение.
