## Дизайн: Новый дизайн страницы обновлений проекта

Страница обновлений получила выразительную шапку с орбитой Reika, мягкими движением и сеткой, крупное сравнение установленной и доступной версий, отдельные карточки истории выпуска и проверки архива. Состояния загрузки, нового и актуального выпуска, ошибки сети и результата SHA-256 оформлены визуально и подписаны текстом. Для маленьких экранов предусмотрена адаптивная компоновка, для системной настройки уменьшения движения анимация отключается.

**Зачем:** На прежней странице важные сведения выглядели одинаково и было сложно быстро понять статус выпуска и следующий шаг.

**Что изменится для пользователя:** Пользователь быстрее видит, есть ли новая версия, где скачать архив и как проверить его целостность. Страница остаётся удобной на телефоне и в тёмной теме.

**Проверки, описанные автором:**
- npm run build — успешно.
- Браузерный smoke-тест: статусы нового, актуального и недоступного выпуска; проверка правильного и повреждённого архива; мобильные ширины и тёмная тема — успешно.
- npm run test:versions: 3 теста пройдены; npm run test:release: 10 тестов пройдены.
- Python unittest: 40 тестов пройдены, 3 Windows-проверки пропущены на Linux.
- npm run check, npm run check:build, npm run release:check и python scripts/chronicle.py validate — успешно.

**Ограничения и известные проблемы:**
- Оформление не меняет источник данных: для проверки новых выпусков всё ещё нужен доступ к GitHub.

**Переход на новую версию:**
- После обновления перезапустите Reika и откройте раздел «Обновления проекта».
