## Новый модуль: Обновления проекта и проверка целостности архива

Добавлен отдельный модуль обновлений и пункт меню. Страница сравнивает текущую версию с последним стабильным выпуском Aspksa/Reika, показывает полное русское описание и ссылку на официальный архив. Выбранный скачанный ZIP проверяется локально по размеру и SHA-256 из GitHub. Обработаны отсутствие интернета, ограничение запросов, отсутствие архива и контрольной суммы, повреждение файла. Ответы кэшируются на минуту, текст выпуска выводится безопасно без исполнения разметки.

**Зачем:** Нужен понятный первый этап обновлений: сведения о выпуске и проверка полученных файлов перед дальнейшим развитием системы.

**Что изменится для пользователя:** В меню появился раздел «Обновления проекта». Пользователь видит версии, читает полный отчёт и получает отдельный результат проверки скачанного архива. Новый модуль и его связи отражаются в разделе «Проект».

**Проверки, описанные автором:**
- Проверены получение метаданных, кэширование, ограничение размера ответа, ошибки сети и неверные сведения выпуска тестами Python.
- Добавлены браузерные проверки русской страницы, безопасного отображения текста, совпадения SHA-256, повреждённого файла, неверного размера и мобильной ширины; выполнение в GitHub Actions.

**Ограничения и известные проблемы:**
- Требуется доступ к GitHub; при ограничении запросов нужно повторить проверку позже.
- Проверка файлов до 256 МБ использует память браузера. Контрольная сумма подтверждает совпадение с архивом GitHub и не заменяет цифровую подпись.
- Установка обновлений, резервные копии и откат в этот этап не входят.

**Переход на новую версию:**
- Распакуйте готовый выпуск и запустите Reika.bat. Откройте новый раздел меню; для проверки скачанного ZIP выберите его на странице.
