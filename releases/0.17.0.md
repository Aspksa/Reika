## Дизайн: Живая карта проекта и исправление ожидания Cloud.ru

Страница проекта получила выразительную шапку с мягкими эффектами, заметный переход к карте, три быстрых действия и панель проблем. Выбор узла карты открывает подробности модуля рядом с картой. Для анализа Cloud.ru запрос ограничен 70 КБ с сокращением длинных файлов, ожидание ответа увеличено до 150 секунд, в интерфейсе виден счётчик ожидания, а сетевой тайм-аут объясняется по-русски. Движение отключается при системной настройке уменьшения анимации. Исправлен порядок завершения: флаг остановки устанавливается до ответа API.

**Зачем:** Прежняя страница затрудняла переход к карте и проблемам, а большой запрос Cloud.ru не успевал завершиться за 45 секунд.

**Что изменится для пользователя:** Быстрые действия помогают перейти к проверке, анализу и проблемам. Карта показывает подробности выбранного модуля без ухода со страницы. Обзор Cloud.ru получает больше времени и выдаёт понятную ошибку при превышении лимита.

**Проверки, описанные автором:**
- npm run build — успешно.
- npm run check — успешно.
- Браузерный smoke-тест: быстрые действия, переход к карте, открытие панели модуля, мобильная и тёмная темы — успешно.
- Python unit-тест: тайм-аут 150 секунд и понятное сообщение — успешно.
- npm run test:versions: 3 теста пройдены; npm run test:release: 10 тестов пройдены.
- npm run check, npm run check:build, npm run release:check и python scripts/chronicle.py validate — успешно.
- После объединения с main 0.16.0: 40 Python тестов пройдены, 3 Windows-проверки пропущены на Linux; 13 Node.js тестов пройдены.
- Браузерный smoke-тест на объединённой версии прошёл: карта, панель модуля, быстрые действия и мобильная вёрстка.
- npm run check, npm run check:build и npm run release:check — успешно.

**Ограничения и известные проблемы:**
- Реальный платный запрос Cloud.ru с пользовательским ключом в облачной среде не выполнялся.
- Длинные файлы сокращаются; анализ модели не гарантирует обнаружения всех ошибок.

**Переход на новую версию:**
- Перезапустите Reika после обновления. Повторите анализ проекта; новый запрос отправит до 70 КБ кода.
