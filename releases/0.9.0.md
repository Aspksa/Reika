## Дизайн: Современный центр архитектуры, граф связей и панель модулей

Раздел «Проект» оформлен в современном стиле Reika: верхняя статусная панель, золотистые акценты, цветные категории, иконки модулей, мягкие карточки, фильтры по кнопке, сетка или список, инспектор справа. Во вкладке «Связи» добавлена настоящая SVG-карта зарегистрированных модулей с направленными цветными стрелками, фокусом, увеличением, перемещением и предупреждением о отсутствующих компонентах. Добавлена лента релизов и блоки развития, проблем и агентов без вымышленных событий.

**Зачем:** С ростом модулей технические списки становятся неудобны, а зависимости важно представлять наглядно и доступно, не теряя совместимости с реестром и историей.

**Что изменится для пользователя:** Выбор модуля открывает его подробности; карта показывает направление и тип связей; фильтры компактнее, визуальные состояния понятнее, есть подсветка и адаптация для мобильных экранов.

**Проверки, описанные автором:**
- Дополнены браузерные тесты верхней панели, панели фильтров, переключения вида, инспектора модулей, узлов SVG и зума.
- Проверки Windows, Linux, Node.js, браузера и русских описаний запускает GitHub Actions.

**Ограничения и известные проблемы:**
- Журналы ИИ-агентов и проблем пока не опубликованы локальным API, поэтому интерфейс показывает честное информационное состояние вместо придуманных событий.
- Даты релизов показываются только если дата есть в API; карта строится по зарегистрированным зависимостям, не по статическому рисунку.
- План развития отображает только изменения, ожидающие релиза, если такие зарегистрированы.

**Переход на новую версию:**
- Откройте вкладку «Модули» для нового каталога и инспектора или «Связи» для карты архитектуры.
- Предыдущие светлая/тёмная темы, журнал выпусков, категории и фильтры сохранены.
