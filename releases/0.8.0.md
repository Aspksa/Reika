## Новая возможность: Вкладки проекта, режимы просмотра и сравнение версий

Добавлены отдельные вкладки «Модули», «Связи» и «История», удобные режимы компактного и подробного отображения, переключатель «Для пользователя / Для разработчика», а также параллельное сравнение двух опубликованных выпусков с их описаниями. Исправлена подача технической информации и скрытие пустого списка файлов.

**Зачем:** Длинный список модулей и релизов перегружал страницу; задачи пользователя и разработчика требуют разных уровней технических подробностей.

**Что изменится для пользователя:** Можно отдельно просматривать модули, зависимости и историю, выбирать плотность карточек, скрывать технические детали и сравнивать две версии рядом.

**Проверки, описанные автором:**
- Добавлены браузерные проверки переключения вкладок, двух плотностей, режимов отображения и сравнения версий.
- GitHub Actions выполняет проверки Node.js, Python, Windows и браузера для кандидата на слияние.

**Ограничения и известные проблемы:**
- Сравнение показывает записи отдельных выпусков рядом, а не автоматически вычисленный файловый diff между произвольными Git-коммитами.
- Доступны только выпуски, присутствующие в истории локального API.

**Переход на новую версию:**
- Откройте раздел «Проект» и выберите вкладку; режимы меняются в верхней части страницы.
- Система версий и автоматический выпуск продолжают работать по прежним правилам.
