## Исправление: Добавить Python в готовый архив Windows

Автоматический выпуск теперь добавляет в ZIP официальный встроенный Python 3.12.10 для Windows x64. Архив Python загружается при сборке выпуска, проверяется по закреплённой SHA-256 и помещается в .runtime/python с путём к корню Reika в python312._pth. Сборка архива выполняется до публикации тега; восстановление прерванной публикации использует тот же упаковщик. Windows CI распаковывает архив в путь с кириллицей, запускает Reika.bat и подтверждает, что выбран встроенный Python.

**Зачем:** Архив v0.20.0 собирался через git archive и не включал Python, поэтому на Windows без установленного Python Reika.bat завершался сообщением «Не найден рабочий Python 3.10 или новее».

**Что изменится для пользователя:** Начиная со следующего выпуска готовый архив Windows x64 запускается без отдельной установки Python. Запуск из исходников остаётся доступен с установленным Python.

**Проверки, описанные автором:**
- Локальная упаковка архива с официальным Python: SHA-256 проверена, исполняемый файл, лицензия и python312._pth присутствуют — успешно.
- Python unit-тесты упаковщика: структура ZIP, путь к Reika и отказ при неподходящем архиве — успешно.
- npm run build — успешно.
- Python unittest: 42 теста пройдены, 3 Windows-проверки пропущены на Linux.
- npm run test:versions: 3 теста пройдены; npm run test:release: 10 тестов пройдены.
- npm run check, npm run check:build, npm run release:check и python scripts/chronicle.py validate — успешно.
- Windows CI распаковал готовый архив в путь с кириллицей, запустил Reika.bat --check и подтвердил выбор встроенного Python 3.12.10; браузер, Node.js и Linux-проверки тоже прошли: https://github.com/Aspksa/Reika/actions/runs/40262358383.

**Ограничения и известные проблемы:**
- Автономный архив рассчитан на Windows x64; исходный ZIP репозитория и старые выпуски не меняются.
- Сборка выпуска зависит от доступности python.org; при сбое до публикации тег не создаётся.

**Переход на новую версию:**
- Скачайте готовый ZIP нового выпуска GitHub и полностью распакуйте его. Установленный Python для этого архива не требуется. Старый архив v0.20.0 по-прежнему требует Python 3.10 или новее.
