## Новая возможность: Поиск, показатели, категории и история раздела Проект

Раздел «Проект» получил поиск модулей по названию, назначению и путям, счётчики модулей, связей, путей и опубликованных записей истории, фильтры категорий и состояний, обновлённые карточки с деталями, визуальные статусы и поиск с фильтрацией истории обновлений. Сохранены существующие типы зависимостей, переходы между связанными модулями, получение сведений по API, светлая и тёмная темы. Локальный API теперь предоставляет зарегистрированные пути компонентов, чтобы их можно было раскрывать на странице.

**Зачем:** Развитие проекта увеличивает число файлов, модулей и записей истории. Поиск и группировка позволяют ориентироваться в них без длинного списка и переписывания текущей архитектуры.

**Что изменится для пользователя:** На странице «Проект» доступны быстрый поиск, четыре показателя, фильтрация по категориям и статусам, раскрываемые списки файлов и связей, поиск выпусков и выбор вида обновления.

**Проверки, описанные автором:**
- Добавлены браузерные проверки поиска по названию модуля и отсутствующих результатов, категорий и статусов, раскрытия файлов, счётчиков и фильтра истории.
- Существующие браузерные тесты проверяют переход по связи, адаптивную страницу и переключение светлой и тёмной тем; полный набор проверок запускается GitHub Actions.

**Ограничения и известные проблемы:**
- Показатель файлов отражает число зарегистрированных путей в реестре, а не точное число физических файлов на диске.
- Категории назначены существующим модулям по их идентификаторам; будущие незнакомые модули попадают в «Другие модули» до регистрации категории.
- История фильтруется среди записей, предоставленных локальным API, который ограничивает количество возвращаемых выпусков.

**Переход на новую версию:**
- Обновите проект обычным проверенным выпуском; дополнительных зависимостей для запуска интерфейса не требуется.
- В разделе «Проект» используйте поиск, фильтры и раскрывающиеся карточки; кнопка обновления сведений сохранена.
