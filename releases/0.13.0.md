## Новая возможность: Настройки внешнего вида и подробный каталог моделей

В настройках проекта появился раздел внешнего вида с выбором светлой или тёмной темы, акцентного цвета (четыре готовых варианта и свой цвет), скругления и масштаба всего интерфейса. Изменения применяются сразу и сохраняются в браузере. Настройки Cloud.ru и каталог моделей оформлены как отдельные части страницы; карточки моделей дополнены описанием типовых задач. Браузерная проверка проверяет сохранение настроек после перезагрузки и отсутствие горизонтального переполнения.

**Зачем:** Пользователю нужны доступные в одном месте настройки интерфейса и понятный выбор модели по задачам.

**Что изменится для пользователя:** Можно настроить внешний вид Reika под себя и сравнить назначение семи моделей перед выбором. Сохранение API-ключа на Windows по-прежнему защищено DPAPI.

**Проверки, описанные автором:**
- npm run build — успешно.
- npm run check — успешно.
- Браузерный smoke-тест прошёл: темы и внешний вид применяются сразу, сохраняются после перезагрузки; 390, 768 и 1440 px без горизонтального переполнения.
- Проверены карточки семи моделей, навигация, Vite и базовые действия интерфейса.
- npm run test:versions — 3 теста пройдены; npm run test:release — 10 тестов пройдены.
- npm run check:build — готовая сборка соответствует исходникам.
- Python unittest discover — 30 тестов пройдены, 3 проверки Windows пропущены на Linux.
- python scripts/chronicle.py validate и npm run release:check — успешно.

**Ограничения и известные проблемы:**
- Описания моделей показывают типовые задачи и не гарантируют доступность конкретной возможности через выбранный API.
- Цены ориентировочные; перед использованием нужно сверить текущий тариф Cloud.ru.
- Защищённое хранение API-ключа проверяется в Windows CI.

**Переход на новую версию:**
- Дополнительных действий не требуется. После обновления перезапустите Reika для загрузки новой сборки.
