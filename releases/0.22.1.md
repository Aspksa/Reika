## Исправление: Автоматическая подготовка Python при запуске Reika без установленного интерпретатора

Если ни локальный, ни системный Python 3.10+ не проходит проверку, Windows-пускатель загружает официальный автономный Python 3.12.10 (x64), проверяет закреплённую контрольную сумму SHA-256, распаковывает его во временную папку, проверяет запуск и атомарно помещает в .runtime/python. Одновременные запуски сериализуются через именованный mutex; неработающая прежняя среда сохраняется в резервной папке. Добавлена возможность использовать проверенный локальный архив без сети и запретить сетевую загрузку. Подключён сквозной тест первого и повторного запуска на Windows, включая путь с кириллицей и символами.

**Зачем:** Архив Code → Download ZIP не включает встроенный Python. На компьютере без Python проект версии 0.22.0 завершает подготовку с ошибкой «Не найден рабочий Python 3.10 или новее» вместо самостоятельного запуска.

**Что изменится для пользователя:** После распаковки исходников Reika сможет самостоятельно подготовить Python без администратора. При использовании готового ZIP-выпуска с Python дополнительная загрузка не требуется. При отсутствии интернета показана понятная причина и способ автономного запуска.

**Проверки, описанные автором:**
- Проверены исходные скрипты start.ps1 и package_release.py: для загрузки закреплены одинаковые версия 3.12.10, адрес и SHA-256 архива.
- Добавлен Windows CI-сценарий реального запуска исходников без системного Python, автоматической установки и повторного запуска без сети; локального выполнения Windows-тестов в этой среде не было.
- Новый PowerShell-тест добавлен в проверку синтаксиса Windows PowerShell 5.1; её выполнение предусмотрено Windows CI.

**Ограничения и известные проблемы:**
- Для первого запуска без Python и без заранее подготовленного архива нужен доступ к python.org; сетевой сбой не маскируется.
- Автоматическая загрузка официального embedded Python предусмотрена только для Windows x64.
- Полную проверку на пользовательском компьютере следует повторить после публикации исправления.

**Переход на новую версию:**
- Скачать обновлённый Reika или готовый Windows ZIP-выпуск и запустить Reika.bat.
- Для запрета автозагрузки установить REIKA_NO_PYTHON_DOWNLOAD=1; для автономной подготовки указать REIKA_PYTHON_ARCHIVE на официальный ZIP Python 3.12.10 (x64).
- Ранее неработающий каталог .runtime/python при исправлении сохраняется как .runtime/python.previous-<id>.
