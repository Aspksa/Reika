REIKA AMATSUHARA

Рэйка Амацухара

Спокойствие той, которой незачем
доказывать своё могущество.

Локальное пространство, которое развивается вместе с вашим проектом. Сейчас здесь есть основа: запуск, главная страница, состояние системы и управление из трея.

Приложение использует стандартную библиотеку Python. Внешние сервисы и учётные записи для запуска не требуются.
