# Reika · Рэйка Амацухара

Локальное пространство с русским интерфейсом, запуском одной кнопкой и управлением из трея Windows. Первая версия — рабочая основа проекта: главная страница, состояние системы и журналы. Чат и модели пока не подключены.

## Запуск в Windows

1. Скачайте репозиторий через **Code → Download ZIP** и полностью распакуйте архив.
2. Дважды нажмите **Reika.bat**. Права администратора не нужны.
3. Дождитесь появления значка Reika возле часов. Браузер откроется автоматически; консоль скроется после готовности трея. Значок может находиться под стрелкой скрытых значков Windows.

Нужен **Python 3.10 или новее**. При запуске проверяются локальный `.runtime\python\python.exe`, `.venv\Scripts\python.exe`, затем `py -3`, `python` и `python3`. Нерабочий кандидат пропускается. При отсутствии подходящего Python окно останется открытым и покажет инструкцию. Официальная загрузка: https://www.python.org/downloads/windows/ . Для установки обычного Python включите **Add python.exe to PATH**; embedded-сборку можно полностью распаковать в `.runtime\python`.

Для запуска готовой сборки нужны Python и встроенный PowerShell Windows. Node.js используется при разработке и сборке интерфейса; собранные файлы уже включены в архив. Ключи API и платные сервисы для основы не требуются. Скрипты ничего не скачивают и не устанавливают автоматически.

Папку проекта можно переместить на другой диск. Запуск рассчитан на пути с пробелами, кириллицей, `&`, `!` и скобками; рабочая папка определяется по расположению файлов проекта.

## Управление

В меню значка Reika:

- **Открыть Reika** — открыть локальную страницу в браузере. Работает и двойной щелчок по значку.
- **Показать консоль / Свернуть в трей** — управлять окном запуска.
- **Открыть журналы** — открыть папку `logs`.
- **Завершить Reika** — остановить сервер и убрать значок.

Закрытие вкладки браузера оставляет приложение работающим. Повторный запуск `Reika.bat` откроет существующий экземпляр из той же папки. Если трей не смог запуститься или неожиданно завершился, консоль останется видимой; выйти можно через **Ctrl+C**. При ошибке окно запуска не закрывается автоматически.

Дополнительные режимы доступны через тот же файл:

```bat
Reika.bat --diagnostics
Reika.bat --no-browser
Reika.bat --no-tray
Reika.bat --check
```

`--diagnostics` включает подробный журнал и оставляет консоль открытой. `--no-browser` отключает открытие браузера, `--no-tray` оставляет приложение в консоли. `--check` проверяет файлы, запуск сервера и соединение, затем завершает работу. Его можно использовать без браузера и трея.

## Интерфейс

- **Главная**: живой статус соединения, время работы, версия и быстрые действия.
- **Система**: адрес, время запуска, Python, процесс, состояние трея и пояснения к журналам.
- **О Reika**: имя и текущие возможности проекта.
- Светлая и тёмная темы; выбор запоминается в браузере. На узком экране навигация перемещается вниз. Анимация учитывает системную настройку уменьшения движения.

Показания обновляются раз в пять секунд. При потере соединения страница сообщает об этом. Адрес меняется между запусками: открывайте страницу через BAT или трей, а не через старую закладку.

## Локальный сервер и данные

Сервер привязан только к `127.0.0.1`. Свободный порт назначает и сразу резервирует операционная система. Доступ из локальной сети не включён. Проверяются заголовки Host и Origin; команды управления требуют отдельный ключ запуска. Этот ключ передаётся процессу трея через окружение и не записывается в URL, журнал или файл состояния.

Сервер отдаёт файлы из списка готовой сборки web/dist/build.json и сведения о состоянии. Перед запуском проверяются версия и SHA-256 каждого файла. Исходники CSS, Node.js, файл сборочного списка и карты исходного кода через HTTP не выдаются. Через HTTP нельзя читать файлы проекта, журналов или произвольные пути на компьютере. Это локальное приложение, а не граница защиты от программ, уже работающих от имени того же пользователя Windows.

Служебные файлы находятся в `.runtime`, журналы — в `logs`. Обе папки исключены из Git. Основной журнал ограничен 2 МБ с тремя архивами; журнал подготовки — 1 МБ с одним архивом. Никакой базы данных в основе нет.

Скрипты PowerShell сохранены в UTF-8 с BOM для совместимости с Windows PowerShell 5.1. BAT содержит только ASCII-команды и использует UTF-8; отложенное раскрытие переменных отключено.

## Node.js и CSS

В проект добавлены **Node.js + Vite** для сборки сайта и режима разработки. Рекомендуется Node.js 24; минимальная поддерживаемая версия — 22.12. Сборка использует точные версии из `package-lock.json`.

CSS находится в `web/styles/`: `theme.css` — цвета, базовые правила и темы; `layout.css` — боковое меню и расположение; `hero.css` — главный блок; `components.css` — карточки и действия; `details.css` — системные разделы; `responsive.css` — мобильная версия и уменьшение движения. Входной файл — `web/app.css`. Логика интерфейса находится в `web/app.js`.

```bash
npm ci --ignore-scripts
npm run build
npm run check
npm run check:build
```

`build` собирает и сжимает CSS/JavaScript, присваивает ресурсам имена с хешами и создаёт `web/dist/build.json` с SHA-256. Папка `web/dist` хранится в репозитории, чтобы ZIP запускался без предварительной сборки. После изменения исходников нужно выполнить `npm run build` и сохранить исходники и новую сборку вместе. `check:build` пересобирает сайт во временной папке и проверяет соответствие готовых файлов исходникам. GitHub выполняет эту проверку автоматически.

Для работы над сайтом сначала запустите Reika через BAT либо `python run.py --no-browser --no-tray`, затем в другом окне:

```bash
npm run dev
```

Vite покажет адрес среды разработки на `127.0.0.1` и будет обновлять интерфейс при изменениях CSS/JavaScript. При занятом порте выбирается следующий. API состояния передаётся в запущенное ядро Python; после перезапуска ядра перезапустите `npm run dev`, чтобы получить его новый адрес. Через Vite не проксируются команды управления приложением. Браузер из BAT открывает готовую сборку; для разработки используйте адрес Vite из консоли. После `npm run build` перезапустите обычную Reika, чтобы загрузить новую сборку.

## Разработка и проверка

```bash
python -X utf8 -B run.py --no-tray --no-browser
python -X utf8 -B -m unittest discover -s tests -v
```

На Linux/macOS доступен консольный запуск; меню Windows и BAT используются только в Windows. Автоматические проверки охватывают HTTP, защиту служебных команд, закрытые пути, блокировку повторного запуска, восстановление после принудительного завершения и запуск из папки с кириллицей и специальными символами. Windows-проверка дополнительно разбирает скрипты встроенным парсером PowerShell, запускает BAT из другой рабочей папки и проверяет готовность и завершение процесса трея. Появление значка и управление окном требуют проверки на реальном рабочем столе Windows.

Отдельная проверка интерфейса в GitHub Actions устанавливает Playwright только в окружение CI, проверяет навигацию, темы, буфер обмена, пять размеров экрана и восстановление соединения. Скриншоты доступны в артефакте `reika-interface`. Это инструменты разработки; для запуска Reika Node.js по-прежнему не требуется.
